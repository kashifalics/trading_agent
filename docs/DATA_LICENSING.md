# Data licensing & usage policy

This is engineering guidance, **not legal advice**. Read each provider's current terms before relying on any assumption below.

## Rules the code follows

* Only official, documented endpoints are called. **No scraping**, no TradingView data extraction, no reverse-engineered/private endpoints, no authentication bypass.
* TradingView's open-source **Lightweight Charts** library is used purely to *render our own backend data*; it is not a data source. TradingView *widgets* are not used as historical-data APIs.
* Provider credentials live only in backend environment variables. They are never sent to the browser.
* Mock/test candles exist only inside the test suite (`tests/`), are generated by a seeded random walk, and are never served by the running app.
* Screenshots are processed locally (OpenCV/Tesseract). No image leaves the machine; no third-party vision API is called.

## What is and is not assumed

| Topic | Position |
|---|---|
| Redistribution | Not assumed permitted for any provider. Stored candles are for the operator's own analysis. Do not expose the API publicly or resell data without confirming terms. |
| Commercial use | Not assumed. Binance public data and Twelve Data free plan each have their own terms (see provider sites); confirm before any commercial deployment. |
| Retention | Candles are stored indefinitely in your own database. If a provider requires deletion on termination or caps retention, add a purge job before relying on that provider commercially. |
| Display | Quotes are shown to the authenticated operator only. Showing provider data to third parties may require a display licence. |
| Derived analytics | Signals/analysis are derived works; whether they may be published depends on the provider's terms. Unresolved → treat as internal-only. |
